---
name: lead-check-blockers
description: Check whether an active discussion still has blockers before routing to the next workflow step.
---

Use this skill as a small explicit checkpoint during an active discussion. Decide whether the topic is blocked by separating user-blocking design questions from autonomous code hygiene, implementation-detail cleanup, and ticket or spec capture gaps.

Use the active conversation and already-loaded artifacts only; do not edit files or start new project investigation. Report the blocking questions, the non-blocking autonomous work, any capture gaps, and the best next workflow step.
