# Verify Discussion

Topic: user request

Use direct project search, wsflow read tools, or host-native one-shot
subagents when useful. Validate the discussion by synthesizing corrected
assumptions, concrete observations, reuse opportunities, and hygiene findings.
Report the revised premise set and steer the conversation toward the direction
that looks best supported. Keep it lightweight and do not edit files.
