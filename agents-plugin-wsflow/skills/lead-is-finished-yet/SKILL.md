name: lead-is-finished-yet
description: Answer whether a design discussion is ready to proceed or still has user-blocking open questions.
---

Use this skill as a small explicit checkpoint during an active discussion. Decide whether the topic is ready to proceed by separating user-blocking design questions from autonomous code hygiene, implementation-detail cleanup, and ticket or spec capture gaps.

Use the active conversation and already-loaded artifacts only; do not edit files or start new project investigation. Report the blocking questions, the non-blocking autonomous work, any capture gaps, and the best next workflow step.
