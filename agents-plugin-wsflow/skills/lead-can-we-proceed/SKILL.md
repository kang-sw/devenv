---
name: lead-can-we-proceed
description: Check whether a design discussion can proceed or still has user-blocking open questions.
---

Use this skill as a small explicit checkpoint during an active discussion. Decide whether the topic can proceed by separating user-blocking design questions from autonomous code hygiene, implementation-detail cleanup, and ticket or spec capture gaps.

Use the active conversation and already-loaded artifacts only; do not edit files or start new project investigation. Report the blocking questions, the non-blocking autonomous work, any capture gaps, and the best next workflow step.
