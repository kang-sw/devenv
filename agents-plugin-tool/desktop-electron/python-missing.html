Python is required

Werkschaft could not run Python. Install it before connecting to your dashboard.

  1. Download the Windows installer from python.org, or run winget install Python.Python.3.13.
  2. In the installer, check Add python.exe to PATH.
  3. Choose Connection → Retry (Ctrl+R on Windows, ⌘R on macOS). Werkschaft checks Python again before connecting.

If your PATH changed, quit and reopen Werkschaft to pick it up. Werkschaft uses WS_MCP_HOLDER_PYTHON when set, otherwise python3. If your installation only provides python.exe, set the user environment variable WS_MCP_HOLDER_PYTHON to its full path and reopen Werkschaft.
