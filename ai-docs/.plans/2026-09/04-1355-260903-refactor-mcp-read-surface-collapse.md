# Plan: 260903-refactor-mcp-read-surface-collapse — Phase 1: Collapse tickets and specs read triples into query

## Relevant Ticket Contract

- Remove `tickets.list`, `tickets.status`, `specs.list`, `specs.status`; the ④-renamed `tickets.query`/`specs.query` survivor already exists and must serve all three prior call shapes: `query()` = old `list`; `query(ticket_stem=X)`/`query(spec_stem=X)` = old `status`; `query(query=…)` = old `find`.
- Fixed param remap at every call site: `tickets.status(X)` → `tickets.query(ticket_stem=X)`; `specs.status(X)` → `specs.query(spec_stem=X)`.
- Scope for the edit: Go registration + dispatch, `runtime.json` ×2, `mcp-tools.md`, `workflow-skills.md`, playbook `rsrc` token call sites (+ wsflow mirror, regenerated), and tests.
- `mental_models.{list,status}` is **not** touched (audit: not a clean superset). Spec pass records a noted exception at `{#260505-mental-model-discovery-tools}` pointing at follow-up `260904-research-mental-models-query-reconciliation` (ticket already exists at `ai-docs/tickets/idea/260904-research-mental-models-query-reconciliation.md`).
- Deprecation posture: one-shot hard cut, no alias for the removed names.
- Acceptance: query survivors return byte-identical output to the removed tools for every prior call shape; removed names gone in-package (grep sweep clean); `go test ./...` in `agents-plugin-tool/` green; playbook paths that called `status` now call `query(ticket_stem)`/`query(spec_stem)` with unchanged results.
- Spec impact: edit existing anchors only, no new stem/heading — `{#260505-ticket-discovery-tools}`, `{#260505-spec-discovery-tools}` (fold list/status prose into query's contract), `{#260505-mental-model-discovery-tools}` (add noted exception + pointer).

- The underlying exported Go functions `wsdoc.TicketsList`, `wsdoc.TicketsStatus`, `wsdoc.SpecsList`, `wsdoc.SpecsStatus` — these stay. They are legitimate internal implementation used by: the CLI above, `internal/wsdoc/references.go`'s `ReferencesTrace` (calls `TicketsStatus`/`SpecsStatus` directly), and `internal/wsdoc/legacy_marker.go`'s advisory resolver (calls `TicketsList` directly). Only the **MCP tool names and their case-dispatch blocks** in `internal/mcp/server.go` are removed.
- Any novel/merged signature design — this ticket only reuses code that already exists (`TicketsStatus`, `SpecsStatus`, `formatTickets`, `formatSpecStatus`), never invents new behavior.
- Layer ② (todo signature merge) and other epic layers.
