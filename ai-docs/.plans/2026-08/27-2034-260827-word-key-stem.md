# Plan: 260827-bug-impl-branch-stem-word-key — Phase 1

## Relevant Ticket Contract
- Goal: entering `enter.implement` for the same ticket across successive phases must produce the same impl-branch stem (so L0 `continue` matches); a different ticket on unmerged work must still reach the L1 `stop`.
- Add an additive deterministic derivation to `internal/wskey` (e.g. `Derive(seed string, words int) string`), hashing `seed` and indexing an embedded `<=5`-char sub-pool (1476 words at 7772 total), leaving `Generate()` untouched.
- In `implement_resolver.go`, when the target carries a `ticket_stem`, the derived stem is **authoritative over a caller-supplied `target.scope_slug`** for ticket targets — not only over the empty-`scope_slug` fallback.
- Inline targets (no `ticket_stem`) keep the current `slugifyImplementScope` label-derived slug path unchanged — no word-key.
- Constraint: do not alter `finishImplementBranchPlanTail`'s `currentBranch == targetBranch` comparison or the L1 `AheadOfMergeRoot` safety stop; only stem production changes. Preserve `continue`/`create`/`current`/`rename` actions and the `impl/<merge-root>/<stem>` encoding.
- Output is 3 hyphen-joined words, worst-case length `5+1+5+1+5=17` chars.
- Optional secondary guidance (skill/convention text: phase suffixes never belong in a branch name) may ship but is not the mechanism.

## Implementation Plan
1. `agents-plugin-tool/internal/wskey/wskey.go`: add `import "crypto/sha256"` and `"encoding/binary"`. In `init()`, additionally build `shortWordPool` (words with `len(word) <= 5`) alongside the existing `wordPool` build, from the same parsed lines. Add `Derive(seed string, words int) string`: for `i in [0, words)`, hash `fmt.Sprintf("%s#%d", seed, i)` with `sha256.Sum256`, take `binary.BigEndian.Uint64(digest[:8]) % uint64(len(shortWordPool))` as the index into `shortWordPool`, and join the `words` picks with `-`. Leave `Generate`/`GenerateUnique`/`wordPool`/`WordCount`/`Words` untouched.
2. `agents-plugin-tool/internal/mcp/implement_resolver.go`: add import `"github.com/kang-sw/devenv/internal/wskey"` (after `"github.com/kang-sw/devenv/internal/wsgit"`, alphabetical). In `normalizeImplementFacts` (`#L594-L600`), replace the empty-`ScopeSlug` fallback block:
   ```go
   if n.TicketStem != "" {
       if n.ScopeSlug != "" {
           warnings = append(warnings, "target.scope_slug ignored for ticket target; branch stem derived deterministically from ticket_stem")
       }
       n.ScopeSlug = wskey.Derive(n.TicketStem, 3)
   } else if n.ScopeSlug == "" {
       n.ScopeSlug = slugifyImplementScope(firstNonEmpty(input.Target.ScopeLabel, input.Target.TicketStem, input.Target.Label, "implementation"))
       warnings = append(warnings, "target.scope_slug missing; derived from target label")
   }
   ```
   This makes the derivation unconditionally authoritative for any ticket target (any non-empty `ticket_stem`), overriding a caller-supplied `scope_slug` too, while leaving the inline (`ticket_stem == ""`) path byte-identical to today.
3. Optional (low cost, skip if time-constrained): add a short convention note (skill/playbook text) that impl-branch stems are identity-derived and phase suffixes never belong in a branch name — secondary reinforcement only, not required for the fix to work.
