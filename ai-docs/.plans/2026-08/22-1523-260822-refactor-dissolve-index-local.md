  wsflow v0007) that, on upgrade, migrates an existing `_index.local.md` into

  the `_index.md` "if not migrated" fallback clause stays; only the
  `_index.local.md` clause goes.

  `ai-docs/manuals/wsflow-mirroring.md`. `AGENTS.template.md`/`WORKFLOW.md` are

  copy is a **generated byte-identical mirror**, not hand-edited; regenerate it
  via the documented `go test` regen commands after editing the canonical

  `documentation-system.md {#260505-project-memory-index}` (make the

  `manuals/*.local.md`, no standalone `_index.local.md`).
- Validate on this repo (devenv): migrate its live `ai-docs/_index.local.md`
  content into the new homes, remove the live read-step from root
  `AGENTS.md`, delete the file, bump the Template Version tag.
- Version-history log entries that merely *name* `_index.local.md` as part of
  a past migration (e.g. v0014 adding it to `.gitignore`) are historical
  records and stay; only *live* read/description instructions are retired.
