## Risk Signals

- `implementer` currently supports Mode B inline brief; Phase 1 should remove
  or sharply demote that path only if all current `lead-implement` dispatches
  can provide a brief file. If inline mode remains, it must not keep the old
  long prompt duplicated in `lead-implement`.
- `PlanPath` optionality can create awkward template prose because rsrc has no
  conditional language. Prefer an explicit empty string/no-plan sentinel with
  simple instructions over clever conditional text.
- Adding variables to `implementer` means every render caller must supply them
  unless the body does not use them. Search all `playbook.render(name:
  "implementer")` call sites and tests before finalizing variable names.
- wsflow `implementer` is not legacy freeform-context eligible. A passing
  wsflow render with undeclared context would be a regression.
- Regeneration tests are env-gated; use `-count=1` or Go test cache may skip the
  write side effect.
- Fresh-reader audit is required by repository rules after playbook edits, but
  it conflicts with a no-subagent execution policy. Treat that as a reported
  blocker unless the caller lifts the no-delegation constraint.

## Stop Conditions

- Stop before source edits if the brief/plan file-first contract cannot be
  represented with declared variables without making all existing implementer
  renders invalid.
- Stop before editing if the current branch has unrelated uncommitted changes in
  target files.
- Stop after prep if asked to prepare artifacts only; this survey does not
  authorize implementation edits.
