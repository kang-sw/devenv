## Risk Signals

- Adding a new rsrc playbook can fail live rendering until manifest regeneration
  completes; regenerate before render verification.
- `implementer-relay` must not become wsflow legacy freeform-context eligible.
  Passing undeclared context should fail in both products.
- Optional `PlanPath` prose can get awkward without template conditionals. Use a
  simple empty-string/no-plan sentinel.
- Do not make the relay prompt depend on a previous implementer transcript.
  Every relay dispatch must be self-contained.
- Avoid broad review-owner cleanup; the dedicated todo ticket remains open.

## Stop Conditions

- Stop before source edits if the current branch has unrelated uncommitted
  changes in target files.
- Stop before source edits if `playbook.render` cannot support the needed
  declared variables without breaking existing implementer/reviewer renders.
- Stop after prep if asked to prepare artifacts only.
