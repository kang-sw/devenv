# Brief: 260519-bug-git-commit-mental-model-notes

## Intent

Add first-class `ws/git.commit` support for commit-body Mental Model Notes so
callers can produce the workflow-required `### Mental Model Notes` subsection
without falling back to manual Git message assembly.

## Scope Boundary

Implement Phase 1 only: add structured Mental Model Notes input for
`git.commit`, render it under `## AI Context`, and preserve all existing
`ai_context` behavior. Do not change the mental-model updater itself and do not
change unrelated commit-message sections.

## Caller-Visible Contract

`ws/git.commit` accepts an optional structured Mental Model Notes input. When
present, the generated commit message contains:

```markdown
## AI Context
- <existing ai_context bullets>

### Mental Model Notes
- <note>
```

The subsection remains absent when the new input is omitted or empty. Existing
`ai_context`, ticket update, spec update, and mental-model update inputs keep
their current rendering and validation behavior.

## Implementation Strategy Decisions

- Add the new input additively to the existing structured commit options rather
  than overloading `ai_context` strings.
- Keep rendering deterministic: notes are bullet-rendered in caller-provided
  order directly after the `## AI Context` bullets and before later top-level
  workflow sections.
- Keep MCP schema and dispatch aligned with the core `wsgit` commit options.
- Keep CLI mirror behavior aligned if the native CLI exposes `git commit`
  structured arguments.

## Rejected Alternatives

- Do not require callers to pass raw commit-body fragments; that would weaken
  workflow parsing and quoting safety.
- Do not make Mental Model Notes a top-level section; the documentation-system
  contract defines it as an H3 subsection under `## AI Context`.

## Approach

- Extend the core commit options and message builder in `agents-plugin-tool/internal/wsgit/`.
- Wire the optional input through `agents-plugin-tool/internal/mcp/`.
- Update CLI/reference documentation only where they describe the public input
  contract.
- Add or extend tests covering omitted, populated, and schema-dispatch behavior.

## Constraints

- `ai_context` remains required and unchanged.
- Empty or omitted Mental Model Notes must not emit an empty subsection.
- The new subsection must not disrupt automatic ticket Result/Edition detection.

## Out of scope

- Changing mental-model-updater parsing.
- Changing `updated_mental_models`, `updated_specs`, or ticket update sections.
- Changing commit result response shape beyond any existing field reflection.
