# Activity Console dogfood Phase 3 brief

Ticket: `260523-bug-ws-dashboard-activity-console-dogfood-usability`
Phase: Phase 3 - Expand Codex prompt and interruption transcript coverage

## Objective

Reduce unsupported Codex native transcript records by normalizing common
fixture-backed prompt, message, tool/MCP, command, patch/apply, and interruption
records into source-neutral `TranscriptBlock` values.

## Scope

- Extend the daemon-owned Codex JSONL transcript adapter in
  `work_root_activity.rs`.
- Add fixture-backed parser tests and route privacy assertions.
- Preserve the browser `ActivityTranscript`/`TranscriptBlock` contract.
- Make remaining unsupported records degraded but useful through bounded
  structural summaries and omission reasons.

## Non-Scope

- No Claude/Gemini native parser support.
- No exec activity source integration beyond Codex-native command records.
- No raw native JSON, paths, session ids, tool output, command output, prompt
  metadata, MCP result payloads, or private record strings in route responses.

## Verification

- `cargo test -p ws-dashboard-daemon work_root_activity`
- `cargo test -p ws-dashboard-daemon work_root_activity_transcript_route`
- Frontend tests only if the public transcript JSON shape changes.
