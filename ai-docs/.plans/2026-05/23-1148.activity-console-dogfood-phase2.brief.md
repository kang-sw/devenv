# Activity Console dogfood Phase 2 brief

Ticket: `260523-bug-ws-dashboard-activity-console-dogfood-usability`
Phase: Phase 2 - Improve compact transcript summaries

## Objective

Make compact transcript blocks useful at one-line density. The default compact
summary should prefer safe semantic content already present in the normalized
`TranscriptBlock` over generic labels such as `Tool call`, `Tool output`, or
`Unsupported transcript record`.

## Scope

- Update frontend transcript block view-model logic for compact summaries.
- Prefer safe fields from `data`, bounded `text`, and render kind before generic
  titles where the title is only a category label.
- Preserve current compact/expanded/terminal mode choices and vertical density.
- Add focused frontend tests for tool call, tool result, status, and degraded
  unsupported-like block summaries.

## Non-Scope

- No new Codex native parser coverage in this phase.
- No backend transcript pagination or tail-page semantics.
- No display of raw backend JSON, native record strings, paths, session ids, or
  tool output snippets.

## Verification

- `cd ws-dashboard/frontend && npm run test:work-root-activity`
- Broader frontend tests/build if the implementation touches shared UI surface
  beyond `workRootActivity.ts`.
