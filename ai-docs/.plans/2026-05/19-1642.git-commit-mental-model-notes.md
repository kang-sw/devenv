- Additive structured commit fields: see `agents-plugin-tool/internal/wsgit/git.go#L404-L412`, `agents-plugin-tool/internal/mcp/server.go#L1823-L1833`, and `agents-plugin-tool/cmd/ws-mcp/main.go#L509-L538` — options, MCP schema, dispatch, CLI flag parsing, and docs are kept in parallel.

## Constraints
- `agents-plugin-tool/internal/wsgit/git.go#L471-L497` — normalization currently requires non-empty `ai_context` and validates paths; the new notes input should be optional and trimmed without relaxing existing requirements.
- `agents-plugin-tool/internal/wsgit/git.go#L753-L777` — ticket Result/Edition detection is scoped to cached diffs under `ai-docs/tickets` and only recognizes `+### Result` / `+#### Edition`; commit-message H3 notes should not be wired into this detection.
- `ai-docs/mental-model/git-workflow-tools.md#L31-L43` — git operation changes are coupled across `wsgit`, MCP dispatch/schema, CLI handler/usage, tests, profile filtering, and docs.
- `ai-docs/mental-model/git-workflow-tools.md#L52-L56` — current documented technical debt says `git.commit` cannot emit H3 subsections under `## AI Context`; implementation should retire or update this note.
- `ai-docs/mental-model/documentation-system.md#L32-L35` — `### Mental Model Notes` has updater semantics but is workflow-internal and optional; absence must remain meaningful fallback, not an error.

## Opinion
- The change is narrow and mostly mechanical, but test coverage should inspect the generated commit body directly in `wsgit` because normal MCP commit responses do not echo the message body.
- The brief aligns with code reality; the only likely scope creep is updating both CLI help/reference docs if the CLI mirror must expose the new repeated field.
- The mental-model docs still describe the gap as active, so a post-implementation doc update should remove or revise that technical-debt statement.
