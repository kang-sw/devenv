# Plan: sync origin/develop into track/agent-v2

## Goal

Merge the latest `origin/develop` (v0.50.5 release work plus later impl merges)
into the `track/agent-v2` line on branch `impl/agent-v2/develop-sync`, so the

## Settled constraints

- The track's Pi/agent child model is authoritative: no auto-close, finished
  children sleep after idle and wake on mail, `agent.stop` removed in favor of
  `agent.interrupt`, `ws/agent.*` replaces `pi.*` worker spawn tools (owner
  decisions (55)-(63) in `261117-feat-ws-agent-tools-mailbox-routing`).
- develop's revival/admission fences, the "deleted" label for children whose
  session file is gone, and the sleeping/deleted dashboard rows are ported onto
  the track model where they still apply. Auto-close-only hooks
  (`autoCloseLocking`, the `keepFinished`/`closeAtStart`/`closeWhenDone` paths)
  are dropped.
- `runtime.json` (three packages): take develop's 0.50.5 version and ranges;
  add the track's four `agent.*` tool entries in the same format. No version
  bump in this change.
- Pi workflow bundles and both `native-pi/first-party-manifest.json` files are
  regenerated by the project's build steps after the merge, never hand-merged.
- Epic ticket `261114-epic-ws-common-session-foundation`: textual union of both
  sides.
- `ai-docs/manuals/ws-mcp.md` auto-merges; remove duplicated or contradictory
  passages between develop's and the track's additions.
