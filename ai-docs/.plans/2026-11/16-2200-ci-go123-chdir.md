# CI: wsagent test uses Go 1.24 `t.Chdir` under a Go 1.23 module

The ubuntu CI job (`GOTOOLCHAIN=local`, Go from `agents-plugin-tool/go.mod`, `go 1.23`) fails to build the `internal/wsagent` test binary:

```
internal/wsagent/pi_probe_cache_test.go:402:7: t.Chdir undefined (type *testing.T has no field or method Chdir)
```

`testing.T.Chdir` was added in Go 1.24. A review repair introduced it in the `"relative"` case of the probe-cache test.

## What to do

1. Replace `t.Chdir(f.root)` with a Go 1.23-compatible equivalent: save `os.Getwd()`, `os.Chdir(f.root)`, and restore the old directory in `t.Cleanup`. Keep the existing comment about Windows drives. If the test (or a parent) runs subtests with `t.Parallel()`, make sure the changed-cwd subtest is not parallel, since a process-wide cwd change is unsafe in parallel tests; say so in the commit if you had to change that.
2. Search the whole `agents-plugin-tool` module for any other API newer than Go 1.23 in Go code (tests included), for example `t.Chdir`, `t.Context`, `b.Loop`, `testing.T.Output`, `strings.Lines`/`SplitSeq`/`FieldsSeq`, `maps`/`slices` iterator helpers added in 1.24, `os.Root`, `crypto/*` 1.24 additions, `weak`, `runtime.AddCleanup`. The fastest proof: build and vet the test binaries with a Go 1.23 toolchain if one is available offline (`ls ~/sdk ~/go/pkg/mod/golang.org/toolchain* 2>/dev/null`). If no 1.23 toolchain is available offline, rely on the search and say so. Do not download anything.
3. Run `GOPROXY=off GOSUMDB=off GOTOOLCHAIN=local go test ./internal/wsagent -run 'TestPiProbeCache' -count=1` and `go vet ./internal/wsagent`.
