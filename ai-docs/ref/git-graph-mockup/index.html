What this is. The session page's git drawer, drawn open, with the .gleft placeholder replaced by the commit graph. Hover a row for the tooltip; click a row (or a working-tree file on the right) for the commit window. Esc, the close button, or a click outside closes it.

Under 760px the graph is hidden (as today's .gleft): the sheet shows the action panel alone, and the commit window has no entry point from the graph. The working-tree file list still opens the window in its working-tree mode (Phase 2).

Phase 1 graph, tooltip, commit window without diffs

  • Lanes for every local branch and its upstream, laid out by the daemon (GET git/log, --topo-order), drawn as inline SVG: dots, merge edges (hollow dot = merge), the checked-out branch's first-parent line held in lane 0, a ring on HEAD.
  • Ref pills: the handle's hammer / trophy icons and stem abbreviation (full name on hover), HEAD mark, ahead/behind against the upstream, upstream folded into the pill when it is on the same commit and an outlined pill of its own otherwise, a folder mark for a branch checked out in a worktree, an outlined folder pill for a detached worktree.
  • Columns: subject, author, relative time, short hash; a commit reachable only from an upstream is italic with a dashed dot; the "Load more" row with lanes continuing dashed (200 per page).
  • Hover tooltip: subject, refs, author, relative time, short hash.
  • Commit window (tracker item-window frame): subject, full message, author / committer with times, copy-hash button (the tracker's ID copy shape), parents (first parent marked as the diff base on a merge); right side file list with status letter, rename source, +/- numstat. The left side is a placeholder (toggle "Phase 1 only").

Phase 2 diff viewer, highlighting, working tree

  • One scrolling multi-file unified diff, a sticky header per file (fold chevron), hunk headers, line numbers, added / removed colours.
  • chroma highlighting as class tokens (.k .kt .nf .s2 .c1 .cm .mi ...) coloured from theme tokens; the first hunk of gitdrawer.go opens inside a block comment and stays a comment (whole-file highlighting).
  • Intra-line marks on paired removed/added lines (gitReadTimeout, truncated lines).
  • On-demand loading: sections load when they near the viewport (skeleton first); over 400 changed lines, binary, and deleted files wait behind "Load diff"; clicking a file in the list scrolls to it and loads it.
  • Working-tree mode: a staged / unstaged / untracked row in the drawer's right panel opens the same window.

Mockup only notes

  • Every commit opens the same file fixture; header data is per commit.
  • Parent hashes are clickable here (navigate the window); the ticket only says they are listed. Keep or drop on review.
  • Lane colours are new tokens (--gl-0..--gl-7), as are the diff and chroma tokens; everything else reuses shipped classes (.gpanel .ghead .gf .gst .gd .idcopy .ia .chip .btn).
  • URL hash for fixed states: #theme=dark&tip=d1&open=d2&file=4&wt=unstaged&p1=1&narrow=1.
