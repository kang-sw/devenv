1. 워크스페이스목록 페이지의 프로젝트 바와 같은 어두운 바입니다. 이름, 경로, 실시간 세션 수가 있고, 누르면 접힙니다. 에픽의 정의대로 루트 워크트리 또는 일반 폴더 단위입니다.
2. 워크트리git worktree list에 나오는 워크트리는 세션이 없어도 모두 보입니다(세션 없는 fix/proxy-launcher는 흐리게). ws가 acquire/release로 빌려 주는 풀 워크트리는 보이지 않습니다. 브랜치 아이콘과 브랜치 이름, 흐린 폴더명(루트는 "루트"), 오른쪽 변경 수. git이 아닌 폴더(notes)는 이 단계를 건너뜁니다.
3. 세션왼쪽 ☆은 "선호 에이전트" 표시입니다. 꺼진 별은 마우스를 올린 행에서만 보이고(키보드 포커스 포함, 터치 화면에서는 흐리게 항상), 누르면 ★로 켜져 늘 보입니다. 자리는 비워 두어 정렬이 흔들리지 않습니다. 첫 줄 오른쪽 시각은 마지막 도구 호출 시각입니다. 둘째 줄은 마지막 메시지 한 줄이고, 사용자가 마지막으로 말한 경우 앞에 "나"가 붙습니다(foldedpaperheron). 정책 질문 수 칩은 남겼습니다.
+ 버튼마우스를 올린 줄에서만 보입니다(터치 화면에서는 흐리게 항상). 레일 머리의 +는 워크스페이스 추가, 워크스페이스 바의 +는 워크트리 추가, 브랜치 줄의 +는 새 세션입니다. git이 아닌 폴더(notes)는 바의 +가 바로 새 세션입니다.
새 세션 창트래커 지원 채팅의 선택 팝업(하네스 / 모델 검색 / 노력 수준 손잡이, dashboard.js supDrawPop)을 그대로 쓰고, 어느 워크트리에서 시작하는지와 시작 버튼만 더했습니다. 선택지 목록도 같은 /support/choices에서 옵니다.
워크트리 추가 창새 브랜치(기준 브랜치 선택) 또는 기존 브랜치. 폴더 기본값은 ../.ws-dashboard-worktrees/<루트 폴더 이름>/<YYMMDD-HHMM>이고, "직접 지정"으로 절대 경로를 넣을 수 있습니다.
워크스페이스 추가 창폴더 선택 창 없이 절대 경로만 받습니다(대시보드를 다른 PC에서 보면 선택 창이 엉뚱한 화면에 뜨기 때문). 붙여 넣은 값은 입력 중에 데몬 쪽 경로로 풀어 보여 줍니다: 앞뒤 따옴표 제거, C:\·/c/·/mnt/c/ → /mnt/c/, \\wsl$\배포판\·\\wsl.localhost\배포판\ → 리눅스 경로, ~ → 홈, 역슬래시 → 슬래시, 끝 슬래시 제거. 상대 경로는 거절합니다. 추가 결과는 알림으로(추가됨 / 이미 워크트리라 변경 없음 / 합쳐짐). 예시 버튼으로 바로 볼 수 있습니다.
선호 핀별을 켠 세션은 자기 워크트리 안에서 맨 위로 고정됩니다(develop의 lemonlaggingstumppreheated). 별을 끄면 원래 순서로 돌아갑니다.
4. 상태 표시하네스 배지(CLAUDE / PI) 테두리를 빛이 돌면 리드가 일하는 중입니다. 로봇이 깜빡이면 서브에이전트가 일하는 중이고, 옆 숫자는 리드가 직접 띄운(1단계) 실행 중 서브에이전트 수입니다. 없으면 로봇과 숫자 자리만 비워 둡니다. 배지 폭을 고정해서 줄마다 로봇과 ID가 같은 세로선에 섭니다. 마지막 메시지 줄은 배지 시작선에 맞췄습니다.
