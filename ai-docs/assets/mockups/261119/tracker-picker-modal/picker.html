세진 오세진SW개발실 · oh-sj
조직 전체는 사람 목록이 아니라 조직 규칙이 됩니다 — 이후 그 조직으로 들어오는 사람도 물려받습니다. 규칙 안의 사람은 흐린 체크로 표시되고 따로 체크할 수 없습니다. 이미 배정된 사람은 잠김 (해제는 담당자 카드에서). 내 도달 범위 밖 조직·사람은 대기 (상대가 수락).
배정자가 확인 사람별
  • 체크 = 적용 후 상태: 모달은 지금 참조 중인 사람을 체크된 채로 엽니다 (이미 참조). 새로 체크 → 추가, 이미 참조인 사람을 해제 → 제거(취소선). 클릭은 아무것도 보내지 않고, 적용을 눌러야 기록됩니다. 취소/Esc/바깥 클릭 = 버림.
  • 목록 = 조직도 (별도 별칭 섹션 없음): 리드 행에는 서로 독립인 선택 2개 — 본인 (그 사람만), 이하 전체 (리드 포함 그 아래 전부). 리드가 조직의 헤드면 이름 옆에 🏢 조직명 배지, 이하 전체는 "조직명 전체 (N명)"으로 읽힘. 헤드가 아닌 리드는 배지 없이 "이하 전체 (N명)". 일반 멤버는 체크박스 1개.
  • 포함 표시: 이하 전체를 켜면 그 아래 행(본인 포함)은 파란 띠 + 흐린 체크 = "조직에 포함"이며 개별 체크가 아닙니다. 개별 체크는 그대로 보존되어 조직을 끄면 되살아납니다. 위 조직이 켜지면 아래 조직 토글도 포함 상태가 됩니다.
  • 공석 조직: 조직은 헤드 멤버에 붙는 별도 객체라 헤드가 비면 붙일 곳이 없음 → 비활성 행 + "관리자가 헤드를 지정해야 선택 가능". 조직도 편집에서 헤드를 정하면 그 리드 행의 배지로 옮겨갑니다.
  • 선택 칩 (위): 조직 선택은 🏢 SW개발1팀 · 4명 한 개, 사람은 사람 칩 (조직에 포함된 사람은 따로 칩 없음). A에서는 칩을 누르면 그 선택이 풀립니다.
  • 참조의 적용: 바뀐 사람마다 item.cc {item, member} / item.uncc {item, member} 이벤트 1개, 한 번의 commit 배치. 조직은 적용 시점 인원(헤드 포함)으로 펼쳐 개별 이벤트 — 이벤트 모양은 지금과 같음 (호환 T0). A의 기본 상태 = cc 4 + uncc 1 = 5건. 조직 자체를 참조로 남겨 이후 합류자도 자동 참조할지는 별도 결정.
  • 배정의 적용: item.assign {item, targets: [사람 id…, {root, include_root: true}…], completion}. 이하 전체 = 헤드 포함 조직 규칙 1개 (지금의 별칭 규칙 모양; 조직 객체 id로 가리킬지는 결정 대기). 완료 방식이 사람마다 갈리면 ("사람별") 완료 방식별로 item.assign 1개씩 — B는 SW개발1팀 규칙 = 배정자가 확인, 범위 밖 한수아 = 담당자가 닫음이라 2개. 이미 배정된 사람은 잠긴 체크 + 배정됨; 해제는 지금처럼 담당자 카드에서. 주제(topic)는 한 명만 — 체크박스 대신 라디오.
  • 높이: 두 모달 모두 고정 높이(640px)에 목록 영역 최소 260px를 보장 — 헤더·선택 칩·안내·하단이 늘어도 목록이 찌그러지지 않고, 목록 안에서만 스크롤됩니다.
