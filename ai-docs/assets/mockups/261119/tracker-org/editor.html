저장 방식 — 3건을 역할 이벤트 3개로 묶어 한 번에 보냅니다. 전부 기록되거나, 하나라도 거부되면 아무것도 기록되지 않고 거부된 항목이 빨간색으로 표시됩니다.
  1. 관리자 지정
  2. 리드 변경 (바뀐 트리의 위쪽부터)
  3. 관리자 해제 (본인 해제는 맨 마지막)
순서는 자동으로 정합니다. 각 이벤트는 앞 이벤트가 반영된 상태로 검사되므로, 이 순서면 최종 트리가 유효한 한 중간 순환이나 권한 상실로 거부되지 않습니다.
관리자 지정 예: 행의 관리자 지정 클릭 → 목록에 관리자 지정 항목이 추가됩니다.
키 추가·폐기와 멤버 제거는 이 창 밖의 기타 역할 이벤트…에서 합니다.
