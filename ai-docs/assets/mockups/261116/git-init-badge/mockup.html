git 폴더가 아닌 워크스페이스에 "git init하기" 버튼

ws dashboard rail mockup, 2026-11-16

일반 폴더 바에는 새 세션 버튼이 없습니다 (lead 세션은 Git 워크트리 루트에서만 시작). 바에 git init 아이콘을 추가하고, 누르면 확인 모달을 띄웁니다.

a일반 폴더 바에 git init 버튼평소 / 마우스를 올렸을 때 (툴팁)
b확인 모달dialog.rdeldlg를 그대로 씀
c완료 후git 폴더가 되어 루트 워크트리 행과 새 세션 버튼이 생김
d모달 오류 상태git을 찾을 수 없음

새 아이콘 i-gitinit = 레일의 브랜치 글리프 + 레일의 “+”. 버튼은 다른 + 버튼처럼 18px 칸, 13px 글리프. 이 폴더의 유일한 다음 단계라서 평소에도 흐리게 보이고 (opacity .6), 마우스를 올리면 진해집니다. .rnew·.rdel처럼 데몬이 도는 컴퓨터의 브라우저에서만 보입니다 (html[data-sysopen]).
