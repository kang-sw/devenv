wswhiteboard topic bar · 1280px ·

상태 단어("구현 중")와 작업자 이름("pi 작업자 5")을 뱃지에서 빼고, 색 + 상태 아이콘 + 시간만 남깁니다. ETA는 같은 뱃지 안에서 경과(큰 글씨) / 최대(우하단 작은 글씨)로 붙습니다. 전체 문장은 호버 팁과 aria-label에 있습니다.

2. 상태별 뱃지 코드의 상태 5종 + 시간 분기

상태 집합: discussing · waiting · researching · implementing · awaiting-confirmation (topic_state.go:18-27). 시계는 implementing + run에만 있고(ago.js:71), researching의 ETA는 정보용 추정치(topic_state.go:45)라 흐르지 않습니다. 닫힌 토픽·진단 상태는 뱃지를 그리지 않습니다(ago.js:42).

지금은 제목과 뱃지가 줄바꿈되어 헤더가 2~3행이 됩니다. 제안은 제목이 먼저 말줄임(…)되고, 아이콘·뱃지·시간은 한 행에 남습니다.

4. 호버 팁 마우스 오버 · 키보드 포커스

작업자 이름, 상태 단어, ETA 전체 문장은 팁으로 옮깁니다. 진행 막대는 의존성 팝오버의 막대(.dw .bar)와 같은 모양입니다.

5. 구현 시 바뀌는 것 CSS만으로는 안 됨

  • ago.js badge()(ago.js:38-79): 라벨·owner span 대신 상태 아이콘 + <span class="t"><b>5</b><small>/60m</small></span>를 한 pill 안에 그림. 따로 있던 .eta / .state-estimate pill 삭제. 매 틱에 b 텍스트와 over 클래스, aria-label만 갱신.
  • page.tmpl topicstate(page.tmpl:42): 서버 첫 렌더도 같은 마크업(아이콘 전용 pill)으로. .tname에 항상 title="{{.Label}}" (지금은 닫힌 토픽만).
  • sprite.svg: 상태 아이콘 5개 추가(i-st-impl/research/discuss/wait/confirm). 구현 중은 스톱워치라서 제목 옆 의존성 시계(i-clock)와 헷갈리지 않음.
  • 팁: .topic이 overflow를 자르므로 .dw .pop처럼 fixed popover로 띄움(deps.js 위치 로직 재사용). 포커스 가능하게 tabindex="0", role="img" + aria-label. 매분 바뀌는 숫자는 aria-label에만 반영(라이브 영역 아님).
  • i18n(wsi18n/tables/*.json): 추가 js.wb.state.eta.tip = “ETA {0}분 중 {1}분 경과”, js.wb.state.over = “{0}분 초과”, js.wb.state.extended = “연장 {0}회 · 최초 {1}분”, js.wb.state.eta.max = “/{0}m”, js.wb.state.estimate.short = “~{0}m”. 기존 상태 이름 키(ko.json:433-437)와 js.wb.state.estimate는 팁에서 계속 사용. js.wb.state.eta(ko.json:439)는 더 이상 화면에 안 나옴.
  • 연장 정보: InitialETAMinutes / ExtensionCount(topic_state.go:35-37)는 지금 data 속성으로 안 내려옴 → 팁에 쓰려면 page.tmpl:57에 data-state-initial-eta-minutes, data-state-extensions 추가.
  • CSS: page-items.css:7-23를 .sb* 규칙으로 교체, 4-5행을 한 행 규칙으로. page-items.css:24의 600px 미디어 규칙(뱃지를 다음 행으로)은 뱃지가 작아져서 삭제 가능.
발견한 기존 버그: ago.js:33은 대기 상태를 stb wait로 그리는데 CSS는 .stb.wb-state-wait(page-items.css:16)만 속 빈 점으로 칠합니다. JS가 첫 틱에 템플릿 마크업(page.tmpl:42, wb-state-wait)을 갈아엎으므로 실제 화면의 “대기”는 꽉 찬 회색 점입니다(owner-before.png와 일치). 새 디자인에서는 클래스 이름을 하나로 통일하면 사라집니다.
