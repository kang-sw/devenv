삭제블록이 빠진 자리. hover → 지워진 내용 팝오버. 클릭 → 고정.
v2 대비+1~1−1최신 버전 헤더에만. 클릭하면 본문 전체를 제자리 비교로 전환(D).
범위최신 버전과 바로 이전 버전만 비교합니다. 접힌 옛 버전(v1, v2)에는 마크를 그리지 않습니다. 블록 단위 짝짓기는 토픽 본문 변경 마크(changes.go diffBodies)와 같은 규칙, 색은 같은 팔레트(page-stream.css:221-223).
