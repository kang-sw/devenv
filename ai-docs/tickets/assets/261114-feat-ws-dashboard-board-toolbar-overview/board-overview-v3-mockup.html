고정
보기
  • 격자 없음. 1열 카드 더미 그대로, 카드 내용이 접혀 올라감.
  • 토픽은 머리줄+recap(2줄로 자름)만, 터미널·파일 카드는 제목줄만.
  • 레일·입력창·고정 열 라벨은 어두워지고 카드 더미와 툴바만 밝음. 열 폭은 그대로라 글줄이 다시 흐르지 않음.
  • 들어갈 때 보던 카드는 같은 높이에 남고 왼쪽에 파란 줄.
나가기
  • 바깥 클릭·Esc·버튼 다시 누름: 펼치면서 원래 보던 자리로.
  • 바깥 첫 클릭은 나가기만 함(그 밑의 레일 항목 등은 안 눌림) — (567)=a.
  • 카드 클릭: 펼치면서 그 카드가 맨 위로 올라오고 깜빡임. 고정 토픽 클릭(넓게): 고정 열로 돌아간 뒤 거기서 깜빡임.
  • 키: ↑↓ 카드 이동, Enter 열기, Esc 나가기. 툴바의 검색은 그대로, 새 터미널·파일은 먼저 나간 뒤 실행.
고정 토픽 (557)·(566)
  • 버튼을 누르는 즉시 한 동작(240ms): 카드가 접히는 동안 툴바 아래에 자리가 벌어지고, 고정 토픽이 접히면서 그 자리로 날아듦. 모두 같은 시간·같은 곡선으로 함께 끝남.
  • 나갈 때는 거꾸로: 펼쳐지는 동안 자리가 닫히고 고정 토픽이 고정 열로 날아가며 펼쳐짐.
  • 도착 지점이 화면 밖이면 날지 않고 페이드.
  • 좁게: 고정 토픽은 원래 맨 위라 날 것이 없음.
  • 구현: 고정 토픽마다 날아가는 복제본 하나 + 높이가 0에서 벌어지는 자리 칸 하나, 접기와 같은 시간·곡선. 열려 있는 동안 보드 순서는 고정(재정렬 보류와 같은 규칙). 실제로는 화면 근처 카드만 애니메이션, 동작 줄이기 설정이면 즉시.
