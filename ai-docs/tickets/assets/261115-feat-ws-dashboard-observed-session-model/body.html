세션 레일의 행은 오늘 그대로 두고(2행에 모델 줄을 넣지 않음), 행에 마우스를 올리면 레일 오른쪽에 그 세션의 정보를 모은 팝업이 뜹니다. 왼쪽 위 에이전트 패널은 변경 없음. 아래 화면은 1280px 대시보드 한 장면이며, 행에 직접 마우스를 올리거나 Tab으로 이름에 포커스해도 같은 팝업이 열립니다.

4. 동작 규칙과 메모

위치 · 동작

  • 팝업은 레일 영역 바깥(오늘 .rpop처럼 페이지 스크립트가 body에 하나 만들어 둠)에 두어, 레일이 SSE로 통째로 교체돼도 사라지지 않고 내용만 갱신.
  • 위치: 왼쪽 = 레일 오른쪽 끝 + 8px, 위 = 행의 위 − 4px, 화면 위·아래 8px 안으로 끌어올림. 1600px 미만의 오버레이 레일(dashboard.css:1578, 폭 340px)에서도 같은 규칙 — 레일이 왼쪽에 붙어 있으니 오른쪽으로만 열면 잘리지 않음. z-index는 --z-popovers(60) > 오버레이 레일 45.
  • 열기: 행 위에 250ms 머무르면 열림, 열린 상태에서 다른 행으로 옮기면 즉시 교체. 닫기: 레일을 벗어나면 120ms 뒤. 드래그 중(.rdragging)·이름 바꾸기 입력 중·행 메뉴가 열린 동안은 열지 않음. 읽기 전용이라 포인터를 받지 않음(.gltip과 같은 방식).
  • 키보드(있으면 좋은 정도): 행의 이름 링크 .rl(행의 유일한 탭 정지점)에 포커스가 오면 같은 팝업을 열고, 링크에 aria-describedby로 연결. Esc로 닫기. 그 이상은 만들지 않음.
  • 터치 기기: 대상 아님. @media (hover: hover)에서만 활성화.
  • 네이티브 title 겹침: 오늘 행에 title이 4곳(하네스 아이콘 hitip, .rid의 reply id, 시간의 data-tl, 하위 행의 메시지) 있음 — 팝업이 켜지면 지우거나 팝업이 대신함(질문 2).

상태별 표기

  • 정상: 관측된 모델 ID 그대로, 별칭(opus) 금지. 긴 ID는 줄임표 대신 슬래시에서 먼저 줄바꿈해 전부 보임(팝업은 공간이 있으니 전체가 목적).
  • 변경됨: 현재 모델이 크게, 그 아래 이전 → 현재 · 14:32 변경. 경고색 없음.
  • 미관측(Codex): 모델 “관측 안 됨”, 숫자 칸은 “—”, 이유 한 줄. 추측값 없음.
  • 중지/오래됨: 마지막으로 본 값을 흐리게 + “마지막 확인 3시간 전”, 컨텍스트 막대는 회색, t/s는 실행 중이 아니라 “—”. 종료 코드/사유 한 줄.
  • 대기 중 세션의 t/s: 마지막 턴의 값을 보일지(“51 · 지난 턴”) 비울지는 질문 3. 시안은 “지난 턴” 꼬리표로 보임.

추천
