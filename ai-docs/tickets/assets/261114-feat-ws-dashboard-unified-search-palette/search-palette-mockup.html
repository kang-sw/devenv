폭 예시 쿼리
대시보드 (배경) — 팔레트에서 결과를 열면 여기에 어떤 화면이 열리는지 표시됩니다.
퍼지 📁 devenv/ · .gitignore

소스 5개 · 동시에 스트리밍

  • 이동·명령 줄: 세션·스토어·액션. 입력창 바로 아래 칩 줄, 즉시 필터. 첫 행에서 ↑ 또는 Alt+0으로 진입, ←→ 이동, ↓ 복귀. ((543)=a)
  • 보드: 토픽·본문·질문/답·번호 항목. 숫자만 쳐도 숫자만 쳐도 ID 퍼지 매칭(접두 우선). (531)은 정확히 그 항목 하나 → 바로 선택되어 Enter로 열림. .123 문법 폐지.
  • 파일: 이름 퍼지, 배치로 계속 도착.
  • 파일·내용 범위: 보고 있는 세션의 프로젝트 폴더, .gitignore 준수 (칩으로 표시).
  • 내용: 데몬 내장 Go 검색(ripgrep 의존 없음), 리터럴, 파일:줄 + 매치 줄. 한도(200) 넘으면 "200+".
  • 트래커: 항목 제목/별칭. 트래커 내용: 본문·댓글 발췌.

취소 가능 · 지연 숨기기

  • 키 입력마다 진행 중인 모든 쿼리 취소, 새 세대로 재시작.
  • 로컬 소스(보드·트래커)는 즉시, 파일·내용은 80ms 디바운스.
  • 이전 결과는 지우지 않고 흐리게 유지 → 새 결과 첫 배치가 오면 교체 (깜빡임 없음).
  • 선택은 같은 결과가 남아 있으면 그 결과를 따라감 — 늦게 온 배치가 커서를 밀지 않음.
  • 슬롯마다 상태: 대기 / 검색 중(n) / 완료(n · 시간) / 한도 / 결과 없음.

폭별 배치

  • 좁게 (<600): 한 목록 + 라벨 탭. 이동·명령 줄은 모든 폭에서 입력창 아래. "전체" 탭은 소스별 상위 3개.
  • 중간 (600–1000): 2열 — 이름 결과(보드·파일·트래커) | 본문 결과(내용·트래커 내용). 포커스된 섹션만 펼침(12), 나머지는 3개.
  • 넓게 (≥1000): 3열 5칸 — 내용이 가운데 세로 전체.
  • 팔레트 폭 = min(대시보드 폭 − 48, 단계 최대폭).

키보드 · 열기

  • 포커스는 항상 입력창(타이핑 유지). ↑↓ 슬롯 안 이동, Tab/Shift+Tab 다음/이전 슬롯(좁게: 탭, 넓게: 칸, 결과 없는 슬롯은 건너뜀), Alt+1–5 슬롯 직행.
  • Enter 열고 닫기, Ctrl+Enter 뒤에서 열기(팔레트 유지), Esc 쿼리 있으면 지우기 → 한 번 더 닫기.
  • 파일 → 미리보기 / 내용 → 미리보기 해당 줄 하이라이트 / 보드 → 스크롤 + 플래시 / 트래커 → 항목 창 / 트래커 내용 → 항목 창의 해당 댓글.
