폭 바로 열기
대시보드의 나머지 영역 (보드 등)
claude · stream-json 리마인더 훅 사고 시스템

대화 목록 조정

  • 도구 묶음 → 호출 목록: 접힌 pill 대신 호출마다 한 줄(상태 · 도구 · 인자 미리보기 · 시간 · 토큰). 3개까지 보이고 나머지는 "+n개".
  • 모든 호출·숨은 이벤트 행이 클릭 가능 → 감사 창. J/K 행 이동, Enter 열기.
  • 숨은 이벤트: 점선 한 줄로 접힘(종류 색 점 + 미리보기). 상단 칩으로 종류별 표시/숨김. 호출에 붙은 훅·리마인더는 그 호출 아래 들여쓰기.
  • 대화 전체 검색: 저장된 출력까지 검색, 맞은 행에 "출력 3" 배지, 감사 창은 그 매치로 열림.

감사 창

  • 탭: 입력 · 출력 · 메타 · 원본 · 연결 이벤트. 원본은 하네스 기록 JSON 그대로.
  • 긴 출력: 줄 번호, 창 안 검색(Ctrl+F, Enter/Shift+Enter 다음/이전), 줄바꿈 토글, 복사.
  • 모델이 본 것 vs 저장된 것: 하네스가 잘라 전달한 지점을 줄에 표시 — 그 아래는 모델이 못 본 부분.
  • 리댁션: 빗금 칩 🔒 종류 · 길이. 원문은 저장 안 함, 규칙 이름만 표시.
  • ←/→ 이전/다음 호출로 창 내용 교체, Esc 닫기. 📌 고정하면 새 창으로 열림(여러 개 비교).

폭별

  • 넓게: 떠 있는 창, 헤더로 끌기, 모서리로 크기 조절. 처음엔 대화 오른쪽에 원래 행을 가리지 않게 배치. 원래 행은 선택 표시 유지.
  • 좁게: 하단 시트(높이 72%), 탭은 가로 스크롤, 메타는 1열.

하네스 중립 ((545)=a, (546)=a)

  • 데몬이 하네스 JSON 스트림의 모든 이벤트를 자체 저장소에 보관(전체 도구 입출력 + 숨은 이벤트), 기존 GC·리댁션 적용.
  • 대화 머리·창 머리에 하네스 배지(claude · stream-json). codex·pi·antigravity 등도 같은 이벤트 종류로 정규화 → 같은 목록·같은 창.
  • 원본 탭 = 정규화 봉투 + 하네스 원본 이벤트 그대로.
  • 시스템 프롬프트: 스트림이 실어 올 때만 세션 시작 행에 표시. API 프록시 캡처 없음.
  • 스트림에 오는 이벤트 종류는 빠짐없이 행으로: 훅 출력, 시스템 알림·리마인더, 컴팩션 요약, 사고, 하위 에이전트 등. 모르는 종류는 "기타" 행 + 원본 탭.
